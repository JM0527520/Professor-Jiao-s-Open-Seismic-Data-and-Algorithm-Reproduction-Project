## 仓库收录范围

仓库保存复现代码、配置、依赖清单、说明文档、数据来源与校验记录，以及已解压的作者参考代码。保留工作区现有的文字报告、对比图和小型结果记录，便于查看复现进展。

原始地震数据、图像数据集归档、数据分卷、模型权重、预测数组、虚拟环境和临时缓存保留在本地，由 `.gitignore` 排除，不随仓库上传，也未启用 Git LFS。

克隆仓库不会自动获得完整数据或预训练权重。请按[数据集总览](公开数据集/README_数据集总览.md)中的原始入口获取资料，并参考 `公开数据集/00_下载记录/` 中的下载脚本、文件清单与核验记录，恢复相同目录结构后，再按工作区说明安装环境和运行验收。

现有报告是本机历史运行记录；其中的本机路径、文件时间和验收状态不能替代新机器上的重新验收。完整训练与全区预测仍需按服务器运行手册执行。

## 来源与许可

第三方作者代码保留原有目录、版本标识及随附的许可和引用说明。第三方代码与数据分别遵循各原作者的许可和引用要求；本仓库未为第三方资料重新授权。
