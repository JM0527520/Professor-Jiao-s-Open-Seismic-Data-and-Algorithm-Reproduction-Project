## 建议资源

首轮建议单张NVIDIA 24GB显卡、8核以上CPU、64GB内存、150—200GB可用SSD。16GB显卡可先试完整形状检查，但未实测显存，不能保证可用。不默认购买多卡或扩大网络。当前有效batch=2，不能为适配显存悄悄改成1；若显存不足，优先更换资源，配置变更另行记录。

系统采用Linux x86_64，建议Ubuntu22.04/24.04，Python3.12，TensorFlow2.18.1、Keras3.15.1、NumPy2.0.2。`tensorflow[and-cuda]==2.18.1`的包元数据固定CUDA12.5组件、cuDNN9.3.0.75；建议使用支持CUDA12.5的驱动（Linux555.42.02或更新），仍以现场GPU检查为准。pip额外依赖负责用户态CUDA库，宿主机仍需驱动；Docker方式另需NVIDIA Container Toolkit。

依据：[TensorFlow安装说明](https://www.tensorflow.org/install/pip)、[TensorFlow构建配置](https://www.tensorflow.org/install/source#gpu)、当前安装包的`and-cuda`依赖元数据。服务器环境使用直接版本约束安装，并在安装后生成该机器的完整锁定清单，不冒充已经验证的Linux锁定环境。

完整Thebe验证区采用磁盘映射：源缓存约5.45GiB；每个模型的概率及两份暂存累计数组共约10.9GiB。两组模型结果、100轮检查点和原始资料另计。不得把整个Thebe重复解压到内存；也不把Windows `.venv`复制到Linux。

## 服务器到位后的执行顺序

新机器或数据位置变化后必须重新验收；之前Windows绝对路径的验收记录不能直接视为服务器验收。

```bash
bash scripts/run_server.sh audit
bash scripts/run_server.sh prepare
bash scripts/run_server.sh preflight --device gpu
bash scripts/run_server.sh smoke
bash scripts/run_server.sh gpu-smoke --server-work
```

前两步读取原数据并检查完整配对、CRC、掩膜和原文件来源。`smoke`仍是CPU32³检查。`gpu-smoke`执行一次完整128³、有效batch=2的GPU参数更新并记录峰值显存；这是单独的工程检查，不保存为基线。后面的正式任务要求当前环境已通过该检查。若环境、显卡或依赖变化，重新执行。

随后正式训练与完整评价分别启动：

```bash
bash scripts/run_server.sh train --server-work
bash scripts/run_server.sh evaluate-synthetic --model author --server-work
bash scripts/run_server.sh evaluate-thebe --model author --server-work
bash scripts/run_server.sh evaluate-synthetic --model trained --server-work
bash scripts/run_server.sh evaluate-thebe --model trained --server-work
```

训练严格执行200训练体、20验证体、100轮；主比较模型预先指定第60轮。评价目录区分原预训练模型与本项目复现模型。Thebe始终只评价原200幅验证剖面；没有TEST入口，也没有Thebe监督微调入口。

Thebe整体验证约3,528个128³窗口（模型轴序24×49×3，步长64，末块贴边），实际耗时待GPU测量。预测保留原始轴序概率体，不阈值裁剪；评价按完整道支持范围处理未知区，保留逐剖面结果、阈值曲线及固定五幅剖面图。

这些命令会逐项执行，脚本不会自动连跑全部任务。使用tmux等保留会话，日志在`outputs/logs`。不要据小样例CPU耗时推算完整GPU训练租用时长；先观察首轮训练和50个预测块的实测耗时。

## 中断后的恢复

例如第12轮完整保存后中断：

```bash
bash scripts/run_server.sh train --server-work \
  --resume outputs/training/faultseg_author_v1/epoch-012.keras
```

以同名完成JSON为准，恢复最新已完成轮次；不要手动改轮数或优化器步数。数据、规则、配置必须与原运行协议一致。

全区预测中断目前**不支持窗口级续跑**。保留失败报告和日志，将失败评价目录整体移至工作区内的归档目录后，重新执行同一评价命令。保持训练run_name和模型不变；不能把部分概率体作为完成结果。完成报告写出前，所有文件均属于未验收结果。

服务器安装和训练阶段产生的新问题，按实际日志修复并记录；是否通过以当前配置对应的实测记录为准；历史BCE检查不能替代当前平衡损失配置检查。
