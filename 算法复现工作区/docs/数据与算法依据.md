# 本轮数据验收与作者算法依据

本轮对应主线的前两项：公开数据核对、已有算法的小规模预测复现。后续是建立基线、验证一项改进、迁移到实际工区。

## FaultSeg3D

固定作者仓库提交 `0ab8ba1c10cb9e5748b0129bfe1a2fe3031b80fe`。

- `utils.py`：`.dat`按float32读取、reshape为128³，逐体计算均值和标准差，然后使用`np.transpose`反转三个轴。
- `predNew.ipynb`：`md=60`对应`fseg-60.hdf5`，验证体使用z-score归一化，模型输出为sigmoid断层概率。
- `unet3.py`：3次2倍池化、最近邻上采样、跳跃连接，主通道16/32/64/128，参数1,459,585。
- `prediction.ipynb`与`model3.json`是另一条旧示例路径，瓶颈通道512，输入使用minmax×255。该路径不能与本轮fseg-60模型和预处理混用。
- 原作者HDF5直接加载；`compile=False`不加载旧训练损失和优化器状态。仅为当前环境中的前向推理兼容，没有移植网络或转换权重。

## Thebe

数据DOI：[10.7910/DVN/YBYGBK](https://doi.org/10.7910/DVN/YBYGBK)。作者代码固定提交`58eae5db2312feca003b9eb179fd9172beeeab5d`。

- 官方NPZ文件头和作者处理Notebook证明分块沿第0轴顺序保存：训练900、验证200、测试703；末个测试分块103。
- `readSGY.ipynb`按`seis_big[il-1001][xl-851]`填入原始数组；二维训练Notebook也把第0轴称为IL。数据论文部分段落把Inline/Crossline称呼交换，另有1803/1804、1537/1573等尺寸笔误。
- 本轮统一用实际数组的`(分区剖面索引,另一横向索引,垂向采样点)`，按作者`transpose(2,1,0)`转到模型。没有凭这些公开描述确定导出后数组的真实起始测线号、采样间隔或深度单位换算。
- [数据说明论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC8220338/)明确限定：特定感兴趣区域与约2–4km深度范围内、垂向断距大于20m的断层。零标签不等于对所有细小断层和全部空间作出可靠否定。
- 该论文说明原始工区不规则，使用零补齐为长方体。因此应区分补零地震道与有效波形中的零交叉。
- 读取和核验没有重新解释、平移、增厚或删改原标签。训练区213个标签位于全零地震道的异常另行记录；未擅自修复。

## 本轮预测边界

- 两个FaultSeg3D验证体，编号0和1，未按预测结果筛选。
- 一个Thebe验证连续体：分区内剖面索引36—163，共128幅，跨越两个官方NPZ分块；其192×128的横向—垂向窗口按参考标签密度确定，选取过程不使用模型输出。
- Thebe窗口是流程检查样例，并非代表性的性能测试集合。固定0.5阈值用于显示和技术重叠检查，没有调参、选模型或声称工区泛化指标。
- 原`getMask`存在后一个轴权重覆盖前一个轴赋值的行为，本轮按原顺序保留；末块位置调整为贴齐有效尺寸以避免额外尾部空块，输出还原为输入尺寸。这些兼容处理均记录，不作为改进效果。
- 全部测试区保持锁定；本轮只核对其文件结构与配对，不绘制样例、不预测、不选阈值。

各原作者代码文件的SHA-256记录在数据验收JSON中，作者模型的SHA-256及30个权重数组核对结果记录在预测JSON中。
