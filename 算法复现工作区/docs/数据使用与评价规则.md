# 数据使用与评价规则 v1

确定日期：2026-11-09。机器配置见`configs/data_policy.json`，实现见`fault_workflow/policy.py`。本规则服务于公开数据基线与实际工区应用，后续改变规则时必须另记版本，不能将不同评价范围的指标直接比较。

## 1. 数据角色与空间边界

| 数据 | 训练用途 | 验证用途 | 测试用途 |
|---|---|---|---|
| FaultSeg3D | 原始train编号0—199，完整128³体 | 原始validation编号0—19，完整体 | 本资料未另设独立TEST，不把验证集称为独立测试集 |
| Thebe | 原始900幅训练剖面；当前只用于数据规则核查，不开展监督微调 | 原始200幅验证剖面，最终评价覆盖全部3174×1537采样 | 原始703幅TEST继续锁定 |

Thebe全局数组分区为`[0,900)`、`[900,1100)`、`[1100,1803)`，端点为半开区间。三维窗口不能跨分区取样；不把相邻剖面随机打散到训练和验证两端。坐标统一是零起始数组索引，尚未确认真实测线号及采样点到物理深度的转换，不能直接把“2—4km”写成某一组数组索引。

## 2. 四种状态

| 编码 | 状态 | 使用规则 |
|---:|---|---|
| 0 | 无效 / 待核查 | 振幅支持范围外，排除监督与评价；即使原标签为1也不强行训练 |
| 1 | 未知 | 支持范围内、参考值0、缺少完整解释确认；不作为确认负样本，也不计为误检 |
| 2 | 确认负样本 | 只有单独确认的完整解释范围内，参考值0，才可使用 |
| 3 | 参考正标签 | 振幅支持范围内的原始正标签，用于参考覆盖检查 |

FaultSeg3D的合成标签视为完整二值参考，全部体素有效，因此0标签为确认负样本。Thebe当前缺少确认的完整解释范围，状态2为空；保持`supervised_training_enabled=false`，不开始Thebe普通二值监督训练。仅有正标签不足以直接训练普通BCE，后续也不擅自引入新的稀疏监督算法。

Thebe如需监督微调，需先补充经解释人员确认的完整解释范围或明确正负解释：文件位置、来源、确认人/方式、版本、空间范围和坐标转换均应记录。振幅范围不能代替该文件；也不以正标签外接矩形、标签距离或模型置信度生成“确认负样本”。这是后续所需的领域依据，本轮已完成规则和接口，未声称已取得该依据。

## 3. 振幅支持范围

在原始轴序`(剖面,另一横向轴,垂向采样)`上，逐条**完整1537点地震道**计算：

1. 全零道：全部排除。
2. 非全零道：保留首个非零值到末个非零值之间的闭区间。
3. 区间内部的零交叉、零振幅样点保留；首尾零段暂按无效候选处理。
4. **先用完整道生成范围，再裁块、转轴。** 如果先裁块，恰好全零的小窗口会误删仍在完整有效波形中的位置。

此规则是可重复的保守振幅包络，不是对每一个排除体素作出地质判断。真实边界需要更可靠的采集有效区或解释范围时，替换包络前另记版本。

全部原始标签保留。不平移、不增厚、不删除标签文件，也不通过将无效正标签改成0来“修复”。训练区原先发现的213个全零道正标签已逐点复核；首尾包络规则还会排除非全零道首尾零段上的正标签，两类分别列明。完整清单由本机扫描生成：`outputs/preparation/振幅支持范围外正标签.csv`；原213点另有`异常标签处理清单.csv`。这两份清单有包含关系，不能把其数量相加。

本轮完整扫描结果：训练区排除1,308个正标签（全零道213个、非全零道首尾包络外1,095个）；验证区排除23,514个，均在非全零道的首尾包络外。合计24,822个。这是该保守规则下的位置计数，不等于认定24,822个标签地质错误。

## 4. 评价口径

**合成数据：** 对全部20个验证体报告严格体素Precision、Recall、Dice及预先固定阈值序列的PR数据。先累计全局TP/FP/FN再计算整体指标，同时保留逐体结果。不以背景占比很高的accuracy作为主要效果结论。

**Thebe：** 以全部200幅验证剖面为范围，计算振幅支持范围内的“参考正标签覆盖比例”和“响应面积占比”，以及被排除的正标签数。覆盖比例只描述模型覆盖了多少已有正标签；响应面积只是响应量，不等于误检率。缺少完整负标注时，正式结果中的Precision、Recall、Dice留空，不将未知区域算作FP或TN，也不称为现场准确率。

过去小样例报告中的Thebe Dice是对供应二值参考的技术重叠检查，保留为历史流程记录，不进入本规则的正式基线表。原样例按标签密度选取，仍只作演示；正式评价不按标签密度筛块，也不沿用作者Thebe制块Notebook的“正标签超过3%才保存”的筛选作为完整验证范围。

阈值0.5固定用于显示；阈值序列在配置中预先写定，不按本次结果挑最优阈值。代表性完整剖面固定为验证区索引0、50、100、150、199，其余剖面仍参与计算。容差匹配或断层带宽调整尚未启用；需要时另报，不混入严格重叠指标。

## 5. 模型选择和比较

第一套训练基线采用作者网络随机初始化，在FaultSeg3D上训练100轮，每轮保存。**预先指定第60轮为主比较模型**，便于与现有`fseg-60`入口对应；这不代表作者证明第60轮最优。第100轮作为训练完成记录保留，不在看过Thebe结果后改选检查点。

分别记录“原作者预训练模型”和“本项目训练复现模型”。Thebe不参与梯度更新和检查点选择；它已用于开发检查，因此正式结果应称公开真实资料验证，不能称独立工区泛化证明。后续一项改进必须沿用同样的数据、掩膜、阈值和模型选择规则。
