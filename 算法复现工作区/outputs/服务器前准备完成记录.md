# 服务器到位前的准备完成记录

完成日期：2026-11-09。对应主线：公开数据核对 → 已有算法复现 → 建立基线 → 验证一项改进 → 迁移到实际工区。

**当前状态：本机可执行的规则、训练兼容实现和运行配置准备已完成；正式基线等待服务器。** 11月3日的预训练推理报告仍保留。本轮仅执行本机CPU数据扫描和小裁块工程检查，没有执行完整训练、全区模型预测、方法改进或实际工区迁移。

## 本轮完成内容

1. **数据使用规则已确定并编码。** 区分无效、未知、确认负样本与参考正标签。振幅支持范围从完整原始地震道计算，再裁块及转轴；保留波形内部零交叉。Thebe缺少完整解释确认的零标签不作为负样本，暂不进行Thebe监督微调。
2. **同一规则已扫描全部训练与验证资料。** Thebe训练900幅、验证200幅逐道核查并完成对应NPZ CRC检查；TEST继续锁定。振幅支持范围外正标签共24,822个：训练1,308个（全零道213个、非全零道首尾零段1,095个），验证23,514个。原始标签原样保留，清单注明排除使用、待人工核查，不把这些位置直接认定为错误解释。
3. **作者训练设置已核实并实现。** 保留作者网络、随机初始化、逐体z-score、原体加垂向翻转体（有效batch=2）、普通BCE、Adam1e-4、100轮及每轮保存。明确第60轮作为预先指定主比较模型；不根据Thebe分数事后挑选检查点。训练保存与恢复包含优化器、轮数、源文件哈希及协议核对。
4. **完整评价代码已准备。** 合成数据覆盖全部20个验证体并累计严格指标；Thebe覆盖全部200幅完整验证剖面，采用磁盘映射和分块预测，按明确规则输出参考覆盖与响应面积。没有确认完整负标注时，Precision/Recall/Dice留空。未把原标签密集演示区域当作正式基线。
5. **服务器配置已准备。** 提供Linux GPU依赖、虚拟环境安装脚本、Dockerfile、分阶段运行脚本、资源建议和故障恢复说明。完整任务要求显式服务器选项、可用GPU及完整形状GPU检查，本机没有执行这些任务。

这些项目已写入[待服务器执行任务](待服务器执行任务.json)，均为暂存状态，没有自动启动或定时运行。服务器实测显存、耗时和结果尚未产生。
